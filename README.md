# SB Link Tracker

ভিডিওতে দেখানো সিস্টেমের নিজের-লিংক / শিক্ষামূলক সংস্করণ। সম্পূর্ণ ফ্রি, শুধু Python stdlib।

## কী করে
1. ড্যাশবোর্ডে আসল লিংক দিলে ছোট ট্র্যাকিং লিংক তৈরি হয়: `/t/<code>`
2. কেউ ক্লিক করলে লগ হয়: IP, দেশ/শহর (ফ্রি ip-api.com), ISP, ব্রাউজার, OS, User-Agent, সময়
3. তারপর সঙ্গে সঙ্গে আসল লিংকে রিডাইরেক্ট (302) হয় — ক্লিককারী স্বাভাবিক পেজই দেখে
4. সব লগ ড্যাশবোর্ডে (`/`) টেবিলে দেখা যায়, ডেটা থাকে `data.db` (SQLite)

## লোকালে চালানো (যাচাই করা হয়েছে 2026-11-25)
```bash
cd ~/workspace/link-tracker
ADMIN_KEY=তোমার_গোপন_শব্দ PORT=8790 python3 app.py
# ব্রাউজারে: http://127.0.0.1:8790/?key=তোমার_গোপন_শব্দ
```
টেস্ট ফল: নমুনা ক্লিকে IP 42.0.7.69 → Bangladesh / Dhaka / AXIATA / Chrome / Android — সঠিকভাবে লগ হয়েছে, রিডাইরেক্ট 302।

## GitHub Actions দিয়ে চালানো
- Workflow: **SB Link Tracker session** — শুধু হাতে চালু (workflow_dispatch), অটো-শিডিউল নেই
- এক সেশন সর্বোচ্চ ~৬ ঘণ্টা; ইনপুট `duration_minutes` (ডিফল্ট 60, সর্বোচ্চ 330)
- সার্ভার Actions রানারে ওঠে, Cloudflare-এর ফ্রি quick tunnel দিয়ে পাবলিক `trycloudflare.com` URL আসে — URLটা Actions রানের লগ / Summary-তে পাওয়া যাবে
- ড্যাশবোর্ড সুরক্ষায় repo Settings → Secrets-এ `SB_TRACKER_ADMIN_KEY` সিক্রেট বসাতে হবে
- সেশন শেষে ক্লিকের ডেটা `tracker-data` নামে আর্টিফ্যাক্টে সেভ হয়

## সীমা ও নিয়ম
- IP দিয়ে আনুমানিক দেশ/শহর পাওয়া যায়, সঠিক GPS লোকেশন নয়।
- নিজের শেয়ার করা লিংকের অ্যানালিটিক্স আর সাইবার-সচেতনতা শেখার জন্য ব্যবহারের উদ্দেশ্যে তৈরি।
- VPN ব্যবহারকারীর আসল IP দেখা যাবে না (VPN-এর IP দেখাবে)।
